Generated by [`notebooks/03_ecg_explainability.ipynb`](../../notebooks/03_ecg_explainability.ipynb) (Captum Integrated Gradients) applied to the baseline checkpoint in [`results/checkpoints/cardio_nexus_ecg_mi_baseline.pt`](../checkpoints/cardio_nexus_ecg_mi_baseline.pt). ## Interpretation

Attribution shows which parts of the signal most influenced this specific model's specific prediction — it is a property of the model, not a verified clinical finding. See [`notebooks/03_ecg_explainability.ipynb`](../../notebooks/03_ecg_explainability.ipynb) for method and limitations.
